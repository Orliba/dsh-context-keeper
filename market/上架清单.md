## 你要做的（三选一优先，按性价比）

### A. 加 `dsh-plugin` topic（必做，30 秒）
仓库页 → 右上 About 右边的齿轮 → Topics 填 `dsh-plugin`（可再 `deepseek-harness`、`dsh`）→ 保存。
加完 dshfind 等一批聚合站次日自动收录。

### B. 提收录 PR（awesome-dsh-plugin，dshmarket 读的就是它）
1. fork `awesome-dsh-plugin/awesome-dsh-plugin`
2. 在其 `data/plugins/` 下新增文件 `Orliba__dsh-context-keeper.yml`（内容 = `market/awesome-dsh-plugin__Orliba__dsh-context-keeper.yml`）
3. 只提交这一个文件（**不要手改 README**，CI/维护者会自动重建）
4. 开 PR，正文用 `market/PR-body.md`
   - 若给我一个带 `repo` 权限的 GitHub Token，我可以自动 fork + 建分支 + 建文件 + 开 PR。
   - 否则你在网页点几下即可。

### C. dsh.so 提交（网页表单，最快拿到反馈）
打开 https://www.dsh.so/zh/submit/ ，粘贴 `Orliba/dsh-context-keeper`，它会自动拉源码、跑安全扫描、生成条目，点「提交到 dsh.so」。
（可选）也可 PR 到 1024Store：`imsai-sh/awesome-deepseek-harness-plugins`，新增 `catalog/plugins/orliba--dsh-context-keeper.json`（内容 = `market/1024store__orliba--dsh-context-keeper.json`），自动合并。

## 描述要改的地方
条目里的 description 是「对代码的声明」，评审会逐条核对，别夸大。以后加了功能（比如 P4 全自动开新会话）记得回来同步描述。
